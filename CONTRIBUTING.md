# Contributing

If you wish to contribute to WadFusion, please respect its intended scope, e.g. do not submit pull requests to add support for random WADs, add new gameplay features, etc.

By submitting a pull request, you agree that the contribution may be licensed under the GNU General Public License version 3 or later, and you certify that you have the right to license the submitted code under said license.

You may not submit code that was generated by an LLM (Large Language Model), modifications of code that was generated by an LLM, code that was modified by an LLM, or code that was written with the assistance of an LLM. Commit and pull request messages or comments may not be generated by LLMs, either. Failure to disclose the use of generative LLMs will result in a ban.
